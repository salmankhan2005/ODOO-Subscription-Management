# Brightloop — Enterprise Subscription Management

Brightloop is an enterprise-grade recurring billing, subscription lifecycle management, and autonomous revenue recovery engine.

---

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm

### Installation

1. Clone the repository and switch to the salman branch:
   ```bash
   git clone https://github.com/salmankhan2005/ODOO-Subscription-Management.git
   git checkout salman
   ```n
2. Install dependencies:
   ```bash
   npm install
   ```n
3. Configure environment variables (optional):
   ```bash
   cp .env.example .env
   ```n
4. Run the development server:
   ```bash
   npm run dev
   ```n
5. Build for production:
   ```bash
   npm run build
   ```
